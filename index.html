03

Artificial Intelligence · Speech Processing · GPU

VoiceCast GPU Project

GPU-accelerated multilingual voice dubbing.

Exploring an AI-powered multilingual dubbing solution that converts audio and video content into different languages while generating natural-sounding speech. The deep-learning models in the pipeline run on NVIDIA GPUs for fast processing.

Key contributions

  • Explored automatic speech recognition and audio transcription.
  • Worked with Faster-Whisper for speech-to-text processing.
  • Explored IndicTrans2 for multilingual translation.
  • Investigated speaker diarization using Pyannote Audio.
  • Explored AI voice synthesis using ElevenLabs.
  • Investigated lip synchronisation using Wav2Lip.
  • Designed a modular speech-processing pipeline.
  • Set up the pipeline to run its speech and translation models on GPU.
  • Explored audio-video synchronisation workflows.
