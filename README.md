# Aravind Reddy · Portfolio

Personal portfolio of Aravind Reddy Kothuru, B.Tech AI & ML student at JAIN (Deemed-to-be University), Bengaluru. Open for full-time and internship opportunities.

**Live site:** https://aravind-reddy-portfolio.vercel.app

## What's inside

- A welcome intro where the letters of "PORTFOLIO" fall into place, followed by a hero with scroll parallax
- Featured projects: AttendNet, FarmRent and VoiceCast
- Skills, certificates, a timeline and contact details

## Tech

Plain HTML, CSS and JavaScript with no build step. Fonts are Inter and JetBrains Mono from Google Fonts.

## Run locally

```
python -m http.server 5500
```

Then open http://localhost:5500.

## Deploy

Hosted on Vercel. From this folder:

```
npx vercel deploy --prod --yes
```
